# 🏘️ Village Admin — Community & Institutional Management Dashboard

[![Next.js](https://img.shields.io/badge/Next.js-15.0-black?style=for-the-badge&logo=next.js)](https://nextjs.org/)
[![Firebase](https://img.shields.io/badge/Backend-Firebase_Admin-FFCA28?style=for-the-badge&logo=firebase)](https://firebase.google.com/)
[![Lucide Icons](https://img.shields.io/badge/Icons-Lucide-FF4081?style=for-the-badge)](https://lucide.dev/)

An administrative back-office portal designed for village community managers and institutional representatives to maintain citizen registries, approve public notices, and track village welfare programs.

---

## 🌟 Features

- **👥 Resident Directory Management**: Add, update, and verify citizen entries, family records, and occupational categories.
- **📢 Notice Board Publishing**: Publish announcements that synchronize with citizen mobile applications in real-time.
- **🔥 Firebase Cloud Synchronization**: Real-time event propagation utilizing Firebase Admin SDK.

---

## 🚀 Setup & Launch

```bash
git clone https://github.com/morshedkoli/village-admin.git
cd village-admin
npm install
npm run dev
```
